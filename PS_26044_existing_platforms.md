# PS 26044 – Existing Platforms Comparison

## Academia-Industry Collaboration for Skill Mapping, Internships & Placement

---

## 1. National Career Service (NCS) Portal

**URL:** ncs.gov.in
**Type:** Government (Ministry of Labour)
**Launched:** 2015

### Features
- Job seeker registration
- Employer job postings
- Career fair organization
- Skill development links

### Drawbacks
| Issue | Impact |
|-------|--------|
| Poor user interface | Low engagement |
| No skill mapping | Generic matching |
| No college integration | Siloed system |
| Outdated technology | Slow performance |
| No verification system | Fake profiles |

### Verdict: **NOT COMPETITIVE** – Outdated, poor UX

---

## 2. Internshala

**URL:** internshala.com
**Type:** Private (VC-funded)
**Founded:** 2011
**Users:** 10M+ students

### Features
- Internship listings
- Job postings
- Skill courses
- Hiring challenges

### Drawbacks
| Issue | Impact |
|-------|--------|
| No college integration | Students register independently |
| No skill verification | Self-declared skills |
| Quality varies | No background checks |
| 25% company commission | High cost |
| Limited rural reach | Urban-focused |

### Verdict: **STRONG COMPETITOR** – But no college integration

---

## 3. LinkedIn

**URL:** linkedin.com
**Type:** Global platform
**India Users:** 100M+

### Features
- Professional networking
- Job postings
- Skill endorsements
- Learning courses

### Drawbacks
| Issue | Impact |
|-------|--------|
| Too broad | Not India/campus specific |
| No college integration | Individual-focused |
| Premium costs ₹₹₹ | Inaccessible to many |
| No skill mapping | Manual profile building |
| Not internship-focused | Job-centric |

### Verdict: **NOT DIRECT COMPETITOR** – Different use case

---

## 4. IIT/NIT Internship Portals

**Examples:** IIT Guwahati, IIT Delhi, NIT portals
**Type:** Institute-specific

### Features
- College-specific placements
- Industry partnerships
- Student portfolios

### Drawbacks
| Issue | Impact |
|-------|--------|
| Siloed per institute | No cross-college reach |
| Limited to elite institutes | Excludes majority |
| No standardization | Each portal different |
| Manual processes | Slow matching |
| No skill mapping | Resume-based |

### Verdict: **NICHE** – Only for premium institutes

---

## 5. Skill India / PMKVY

**URL:** skillindia.gov.in
**Type:** Government scheme
**Focus:** Skill training certification

### Features
- Skill certification
- Training partner network
- Sector Skill Councils
- Apprenticeship programs

### Drawbacks
| Issue | Impact |
|-------|--------|
| Training focus only | No placement guarantee |
| No industry matching | Certification without jobs |
| Quality inconsistency | Varied training centers |
| No college integration | Parallel system |
| Poor tracking | Low completion rates |

### Verdict: **COMPLEMENTARY** – Not a direct competitor

---

## 6. naukri.com

**URL:** naukri.com
**Type:** Private (Info Edge)
**Founded:** 1997
**Users:** 50M+ job seekers

### Features
- Resume database
- Job postings
- Recruiter tools
- Skill assessments

### Drawbacks
| Issue | Impact |
|-------|--------|
| Job-focused | Not internship/skill mapping |
| No college integration | Individual registration |
| Quality varies | Fake resumes exist |
| ₹₹₹ for recruiters | High cost |
| Not campus-specific | Generic |

### Verdict: **INDIRECT COMPETITOR** – Job-focused

## Gap Analysis

**What existing platforms DON'T do:**
1. ❌ College ERP integration
2. ❌ Verified skill profiles (college-validated)
3. ❌ Ayush-specific skill mapping
4. ❌ Government-backed quality assurance
5. ❌ Cross-college standardized credentials

**PS 26044 USP:**
- First platform with **college-integrated skill verification**
- Ministry of Ayush backing = credibility
- Ayush-specific = niche focus
- Free for students + affordable for colleges
