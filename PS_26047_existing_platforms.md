# PS 26047 – Existing Platforms Comparison

## Patient Case-Taking Software for Ayush Practitioners

---

## 1. A-HMIS (Ayush Hospital Management Information System)

**URL:** ahmis.ayush.gov.in
**Type:** Government (Ministry of Ayush)
**Launched:** 2020
**Adopted by:** 5,386 facilities (as of July 2026)

### Features
- Patient registration
- Electronic health records
- Inter-facility referrals
- OPD/IPD management
- ABDM integration (ABHA)

### Drawbacks
| Issue | Impact |
|-------|--------|
| Hospital management focus | NOT case-taking specific |
| No Prakriti assessment | Missing Ayush diagnostics |
| No Nadi Pariksha | No pulse diagnosis |
| No Jihva Pariksha | No tongue analysis |
| Complex interface | Hard for small clinics |
| Internet required | Offline not supported |

### Verdict: **COMPLEMENTARY** – Hospital mgmt, not case-taking

## Gap Analysis

**What existing platforms DON'T do:**
1. ❌ Structured Prakriti assessment
2. ❌ Nadi Pariksha (pulse diagnosis) input
3. ❌ Jihva Pariksha (tongue analysis)
4. ❌ Ashtavidha Pariksha (8-fold examination)
5. ❌ Panchakarma treatment protocols
6. ❌ Voice-first case-taking
7. ❌ Offline capability
8. ❌ ABDM + Ayush-specific combined

**PS 26047 USP:**
- **First platform specifically designed for Ayush case-taking**
- Voice-first = fast documentation
- Complete Ashtavidha Pariksha support
- ABDM compliant + Ayush-specific
- Works offline for rural clinics
